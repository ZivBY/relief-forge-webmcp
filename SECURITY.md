# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the latest tagged
development release. Older development snapshots are not maintained.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory flow for this repository, including reproduction steps and the
affected version or commit.

Relief Forge runs locally and does not intentionally upload project data. A
report should distinguish application security from malformed export files,
browser limitations, slicer behavior, and physical manufacturing concerns.

Never include passwords, access tokens, private customer files, or other secrets
in a report or test fixture.
